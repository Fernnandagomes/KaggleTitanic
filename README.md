# Titanic: Previsão de Sobrevivência 

Este projeto utiliza Machine Learning para prever quais passageiros teriam sobrevivido ao desastre do Titanic com base em dados como idade, sexo e classe social.

## Objetivo
Construir um modelo de classificação que identifica padrões nos dados históricos do Titanic para realizar previsões sobre novos passageiros.

## Tecnologias e Bibliotecas
* **Python**: Linguagem principal.
* **Pandas**: Manipulação e limpeza de dados.
* **Scikit-Learn**: Criação do modelo de Machine Learning (Random Forest).
* **Seaborn/Matplotlib**: Visualização de dados.

## O que foi feito
1. **Análise de Dados**: Exploração da taxa de sobrevivência por classe e sexo.
2. **Pré-processamento**: Tratamento de valores nulos e conversão de variáveis categóricas (texto para número).
3. **Modelagem**: Treinamento de um algoritmo de **Random Forest**.
4. **Avaliação**: O modelo foi validado usando uma Matriz de Confusão e métrica de Acurácia.
